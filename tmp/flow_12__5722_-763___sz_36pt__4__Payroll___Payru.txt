[5940,2615 | sz:28pt] Payrun Creation:

Creating a Payrun happens in two steps:

- Select the payroll scope, such as employee type, salary structure, and period.
- Select the employees to include.
- Continue only moves to employee selection. A Payrun is created only after clicking “Create
Payrun”.
Only the selected employees should be included in that Payrun.


Payruns & Payslips:

A Payrun represents payroll processing for a particular period.
Each selected employee should have a Payslip linked to the Payrun.
Computing payroll should use the employee’s applicable contract and selected salary structure.
Payslips should show understandable components such as Basic, Allowances, Deductions, Gross,
and Net Salary.
Payroll issues, such as missing required information or duplicate payslips, should be visible to the
user.


Payroll Workflow:

The intended flow is broadly:

Draft → Compute → Validate → Mark Paid

Paid/finalised payroll should remain available as historical data.


Salary Structures & Salary Rules:

A Salary Structure contains the rules used to calculate salary.
Salary Rules can represent Basic Salary, Allowances, Deductions, Gross, Net, etc.
Rules should be processed according to their sequence.
Different calculation methods may be supported, such as fixed amounts, percentages, or formulas.

Participants are free to design the calculation engine as long as salary rules actually drive Payslip
calculations.


Payslip PDF:

Users should be able to generate/print a Payslip showing the employee’s payroll calculation for
that period.
Sending Payslips can also be supported from the Payrun.


Payroll Dashboard:

The dashboard should use actual data created through the HR and Payroll flows rather than
hardcoded values.

It should provide useful payroll/HR insights such as:

Salary totals
Payslip status
Salary by department
Salary trends
Attendance overview
Time Off overview
Payroll warnings or items requiring attention

Filters such as Period, Department, Employee Type, or Company should affect the relevant
dashboard data.
