[8169,1597 | sz:20pt] Computation Note:
 - Fixed Amount: uses the exact value entered in the rule, e.g. Meal Allowance = 2,000.
 - Percentage: calculates the rule as a percentage of a selected base such as Contract Wage,
Basic Salary, or Gross Salary, e.g. HRA = 20% × Basic Salary.
 - Python Code / Formula: is used for advanced calculations where fixed or percentage methods
are not sufficient, such as attendance-based salary, overtime, unpaid leave deductions, or
calculations using multiple salary-rule values.
